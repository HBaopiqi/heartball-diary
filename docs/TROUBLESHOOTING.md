# 卡在哪一步，就从哪里检查

[返回首页](../README.md) · [小白上手](QUICKSTART.md) · [MCP 接入](MCP.md)

先在项目目录运行：

```sh
npm run doctor
```

Windows PowerShell 可以使用 `npm.cmd run doctor`。Agent 可以运行 `node scripts/doctor.mjs --json` 读取结构化结果。检查涵盖本机运行环境、依赖和端口，不会用它来证明心力球账号已经授权。

## 下载和安装

| 看到的问题 | 下一步 |
| --- | --- |
| `node` 或 `npm` 不是可识别的命令 | 安装 [Node.js LTS](https://nodejs.org/en/download)，重新打开终端；检查 `node --version` 和 `npm --version` |
| Node 版本低于 22 | 升级到满足要求的 LTS 版本，重新检查版本号 |
| 提示找不到 `package.json` | 进入解压后的项目根目录，确认这里能看到 `package.json` |
| PowerShell 提示 `npm.ps1` 无法运行 | 改用 `npm.cmd run setup`、`npm.cmd start`，或直接双击 `start.cmd` |
| 启动脚本无法找到其他文件 | 完整解压 ZIP 后再运行，不在压缩包内部运行 |
| npm 下载超时、连接失败 | 检查报错中的目标域名、当前网络和自己已有的代理配置，再运行 `npm run setup`；不要同时启动多个安装任务 |
| 磁盘空间或写入权限不足 | 把项目完整移到可写的个人目录，保留 `data/`；处理空间后再安装 |

GitHub 项目下载、npm 依赖下载、心力球 MCP 连接各自需要网络。使用你自己的网络配置；脚本不会自动改全局下载镜像、代理或证书验证。需要帮助时，给 Agent 看具体错误和发生在哪一步。

## 网站打不开

**浏览器提示无法连接：**确认启动窗口仍在运行，使用它显示的完整 `http://127.0.0.1:端口` 地址，在同一台电脑访问。关闭终端后需要重新启动。

**`EADDRINUSE` / 端口被占用：**可能已有一份服务在运行。先检查那个窗口；不要直接结束不认识的进程。需要另选端口时，只对本次终端设置：

Windows PowerShell：

```powershell
$env:PORT='3211'
npm.cmd start
```

Mac / Linux：

```sh
PORT=3211 npm start
```

然后使用新显示的网址。更换端口后，浏览器收藏存储和授权回调地址也可能变化，必要时重新授权。

**只看到虚构示例：**你可能打开了 `public/index.html`。连接心力球需要使用启动脚本给出的本地服务地址。

**页面没有 MCP 表单：**直接打开 HTML 属于离线阅读模式；使用本地服务后，在“档案”里找到“连接心力球”。

## 心力球连接不上

| 看到的问题 | 下一步 |
| --- | --- |
| 授权链接过期、授权跳转失败 | 保持本地服务运行，重新点击“连接 / 授权”，在新页面登录并完成最后的授权确认 |
| 已在别的 Agent 授权，但网站仍要求登录 | 两份客户端的授权分别保存；完成网站自己的授权即可 |
| 提示缺少 `recall_memory` 或 `recall_note` | 核对是不是对应心力球账号的 MCP 服务，不能填普通网站链接 |
| 地址包含查询参数、账号密码或使用了不支持的传输方式 | 保留官方接入说明并反馈兼容需求，不把私有令牌贴到 Issue |
| 已连接但没有记录 | 核对授权账号、查询日期、原始录音是否已由心力球服务处理完成，再同步；空响应不代表那段时间没有活动 |

本项目不负责开通设备或账号的 MCP 权限。预填地址无法使用时，向服务方确认账号支持情况和当前接入方式。

## 有原文，但没有我想要的总结

**显示“待整理”：**原文已经取得，还需要 Agent 执行 `heartball-sync`，或使用[上传原文包的方式](QUICKSTART.md#生成第一份每日回顾)。网站自身不会调用模型自动写回顾。

**只查到最近几天：**首次默认查询最近 7 个自然日。需要更早资料时，明确对 Agent 说“同步从某年某月某日开始的心力球记录，并整理这些日期”；它应按真实起点请求服务，保留已归档内容。

**晚上的内容没出现：**比较“查询截至”与“实际原文终点”，稍后再次同步。设备服务处理完的录音可能晚到；不要用空缺推断用户没有说话或活动。

**导入被拒绝：**确保选中了完整的已整理资料 JSON，不是原文包外层对象。用最新整理包里的 `dataset` 作基底，保留原始字段、`sourceHash`、`dates` 和所有来源。若提示版本过期，重新同步、下载并整理后再导入；不要删掉校验字段来绕过报错。

**更换电脑后收藏消失：**收藏保存在浏览器。迁移前使用“全部记录 → 导出资料”保存带收藏的 JSON，再在新环境导入对应资料库。

## Skill 没有出现

确认 Agent 打开的就是项目根目录；Claude Code、TRAE、Qoder 运行[对应安装命令](AGENT_GUIDE.md#已有项目只想配好-skill)，然后按工具说明刷新技能或重新打开项目。

自动发现未生效时，直接说“读取这个项目 `.agents/skills/heartball-sync/SKILL.md` 并按它执行”。这只补充项目说明，不会给一个没有本地工具的聊天网页增加终端能力。

## 反馈时提供什么

在 [Issues](https://github.com/HBaopiqi/heartball-diary/issues) 说明：操作系统、Node 版本、使用的 Agent/浏览器、操作步骤、错误全文和期望结果。不要附完整 `data/`、授权信息或私人转写；只保留复现所需的脱敏内容。
