# 把自己的心力球接进来

[返回首页](../README.md) · [首次启动](QUICKSTART.md) · [常见问题](TROUBLESHOOTING.md)

MCP 可以理解成“让程序获得你授权的心力球记录的连接方式”。本项目由电脑上的本地服务连接心力球；不同 Agent 可以通过这份本地档案进行整理。

## 先分清两个地址

| 地址 | 用途 | 填在哪里 |
| --- | --- | --- |
| `http://127.0.0.1:3210`，或启动终端显示的其他端口 | 你电脑上的日记网站 | 浏览器地址栏 |
| 心力球 MCP 服务的完整 HTTPS 地址 | 读取你账号的原文 | 网站“档案 → 连接心力球 → MCP 服务地址” |

请先使用 `start.cmd`、`bash start.sh` 或 `npm start` 启动本地服务。直接打开 `public/index.html` 是离线阅读方式，不显示 MCP 连接表单。

## 服务地址从哪里来

当前程序为新资料库预填以下地址：

```text
https://beluga-server-cn.heytapmobi.com/beluga-mcp/gateway
```

这是**本项目当前配置的服务入口**，不代表所有账号、地区或未来服务版本都保证可用。可以先保留预填值尝试授权；如果心力球官方提供给你的接入说明不同，使用其给出的完整地址。也可以核对你在其他助手中已成功连接的 MCP 配置。

目前没有在此文档中确认一个适用于所有用户的心力球应用内获取菜单。找不到账号对应的接入方式时，请向心力球官方支持确认，不要把官网首页、分享链接或日记网站地址填在这里。

本版本支持标准 Streamable HTTP 与 OAuth，并要求服务提供 `recall_memory`（全时记）和 `recall_note`（随口记）。地址不接受嵌入账号密码、查询参数或片段的形式；如果官方给你的接入方式不同，请先反馈兼容需求，保留原始说明。

## 按这个顺序连接

1. 在本地网站右上角点击 **档案**。首次可以直接使用默认“我的资料库”，也可以输入名字创建新资料库。
2. 找到 **连接心力球**，确认 MCP 服务地址；更改过时点击 **保存设置**。
3. 点击 **连接 / 授权**。若出现 **打开心力球授权页面** 按钮，点击它。
4. 在服务给出的授权页面登录**自己的心力球账号**并确认授权，保留本地服务的启动窗口。不要将密码或验证码发给 Agent。
5. 授权成功后通常会跳回本地网站。回到对应资料库，再点击 **连接 / 授权** 确认；成功时会提示“心力球已连接”。
6. 点击 **同步原始记录**，等待结束，再点击 **载入最新记录**。

> 连接成功只代表可以访问服务；看到原文数量增加才说明取得了资料；看到回顾且整理状态完成才说明完成了整理。

程序会检查两个工具是否都存在，按分页取回资料。授权页面出错、任一接口失败或分页不完整时，这次同步不会提交成成功结果。

## 账号切换和授权失效

为另一个账号创建单独资料库，再在该资料库完成授权。浏览器可能记住上一次登录的账号，授权时请核对显示的身份；**创建资料库本身不会替你切换服务商账号**。

授权跳转超时、页面提示失败或本地服务已被关闭时，保持服务运行，重新点击“连接 / 授权”，使用新打开的授权链接完成流程。重启服务后已有本地授权信息可能被用于重连；如果服务要求重新登录，按页面提示操作。

GitHub 下载账号、Agent 使用账号和心力球账号是不同用途的账号。下载这个公开仓库无需给它你的 GitHub Token。

## Agent 是否也要配置 MCP？

按推荐流程使用时，**不需要**。网站连好 MCP 后，Agent 从本机 API 取得完整原文包，再把整理结果导入同一个资料库。

若你已在 Agent 中连接了心力球 MCP，可把它用于核对，但那份授权不会自动传入网站；网站仍需完成自己的授权。已有来源后续补句时，先通过网站同步取得新版本，再下载新整理包，避免用旧资料覆盖修订记录。

不同网络环境下，GitHub 下载、npm 依赖安装和心力球服务连接是三条独立链路。某一项成功不代表其他两项也已连通。排查方式见[常见问题](TROUBLESHOOTING.md)。
