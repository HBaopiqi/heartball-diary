# 心力日记首次配置

在本仓库中执行，先读取根目录 `AGENTS.md` 和 [AGENT-SETUP.md](../../../AGENT-SETUP.md)。规范流程与 API 约定由该文件维护。

确认环境能够访问用户本机。按配置流程完成环境检查、项目依赖安装、当前 Agent 技能发现、服务健康检查和本人账号授权，然后转入 [heartball-sync](../heartball-sync/SKILL.md) 完成首次记录整理。

保留已有项目、资料和授权；只配置本项目所需内容。安装权限与账号登录由实际环境和用户决定，不能通过提示词跳过。默认地址和默认资料库以运行中的服务为准。

下载或授权失败时保留已完成步骤，说明具体阻碍和下一步；区分配置、连接、同步和整理状态。给新手的交接应包括访问地址、启动方法、数据位置和下次更新的一句话。
